# Kairos

Kairos is a Chrome sidepanel assistant that can read the current page, reason over its content, and take simple browser actions through a Next.js API powered by the Vercel AI SDK.

## What It Does

- Opens as a Chrome sidepanel extension
- Sends chat requests to a local Next.js server
- Lets the model inspect the current page as text or sanitized HTML
- Supports basic browser actions such as clicking elements and navigating to URLs
- Uses OpenAI models through the AI SDK

## Architecture

```text
apps/
├── extension/  Chrome extension built with CRXJS, React, Vite, Tailwind CSS
└── server/     Next.js API that streams model responses and exposes tool schemas
```

The extension collects page context in the active tab and returns tool results back into the chat loop. The server handles model calls and streams assistant responses from `/api/chat`.

## Requirements

- Bun 1.2+
- A Chromium browser with developer mode enabled
- An OpenAI API key

## Setup

Install dependencies:

```bash
bun install
```

Create local environment files from the examples:

```bash
cp apps/server/.env.example apps/server/.env.local
cp apps/extension/.env.example apps/extension/.env
```

Set the required values:

- `apps/server/.env.local`
  - `OPENAI_API_KEY`: OpenAI API key used by the server
  - `CORS_ORIGIN`: extension origin allowed to call the API
- `apps/extension/.env`
  - `VITE_SERVER_URL`: base URL of the local server, for example `http://localhost:3000`

## Development

Start both apps:

```bash
bun dev
```

Or run them separately:

```bash
bun dev:server
bun dev:extension
```

The Next.js API runs on `http://localhost:3000` by default.

## Load The Extension

1. Start the extension dev server with `bun dev:extension`.
2. Open Chrome and go to `chrome://extensions`.
3. Enable Developer Mode.
4. Load the unpacked extension output generated by the CRXJS/Vite workflow.
5. Open the extension sidepanel and connect it to the local server configured in `VITE_SERVER_URL`.

## Available Scripts

- `bun dev` - run the full workspace in development
- `bun build` - build all workspace apps
- `bun check-types` - run TypeScript checks across the workspace
- `bun check` - run Biome with fixes
- `bun dev:server` - start the Next.js server only
- `bun dev:extension` - start the extension only

## Core Capabilities

The server currently exposes four model tools:

- `readPageHtml`
- `readPageText`
- `clickElement`
- `navigateTo`

These tools let the assistant inspect the active page before responding and perform basic interactions when requested.
